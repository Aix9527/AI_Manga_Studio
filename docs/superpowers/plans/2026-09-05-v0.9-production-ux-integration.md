# v0.9 Production UX Integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Convert the remaining v0.8 half-wired production controls into persisted, testable actions without bypassing the existing orchestration/QC contracts.

**Architecture:** Keep the unified Studio UI and existing Job/Workspace services. Add a narrow workspace endpoint for shot-level director metadata, wire the director inspector to that endpoint, synchronize saved director settings into the existing `production_plan.json` runtime contract, and make the timeline export action reuse existing compose/export jobs instead of showing a local-only success notice. Keep Advanced Canvas execution fail-closed until a real resumable stage-start contract exists; expose that state clearly rather than pretending execution succeeded.

**Tech Stack:** FastAPI, Pydantic, SQLite, React 18, TypeScript, Zustand, Vitest/Testing Library.

**Spec:** `docs/superpowers/specs/2026-08-21-unified-local-studio-design.md`

## Global Constraints

- Local-first execution and storage.
- Do not bypass QC/review gates.
- Preserve asset version history and active-version semantics.
- Do not silently route an H3 Unified request to an incompatible provider/runtime.
- UI actions must reflect actual backend state; no fake-success notices for production actions.
